## 已验证链路

1. 测试截图/文本样本进入 Collator 摄入入口。
2. Tesseract OCR 提取候选文本并保留来源上下文。
3. Candidate 记录进入人工确认；未经确认的数据不得越过治理门。
4. SOP Gate 输出 `PASS`、`NEEDS_REVIEW` 或 `REJECT`，并保留审计原因。
5. 通过治理门的数据写入测试 Base；重复请求验证幂等，测试记录按精确 ID 清理。

## 三条核心业务规则

- BR-01：原始输入与结构化结果必须保留可追溯关联。
- BR-02：高风险或低置信度内容必须进入人工确认，禁止直接写入正式业务流。
- BR-03：测试写入必须幂等、可审计、可精确清理；通知默认关闭。
