# AI BUSINESS OS — 3 分钟总览脚本

## 讲解顺序

1. **定位（30 秒）**：我是 AI / Agent 产品经理，负责把客户交互、业务数据和多模态能力组织成可验证产品，并把人工复核、治理和评估放回系统里。
2. **系统（45 秒）**：四层依次是运营与人工复核、Agent 与自动化、业务数据与记忆、适配器/API/模型；闭环是业务问题 → 数据/知识 → Agent/模型 → 人工复核 → 评估回流。
3. **案例（90 秒）**：Service Agent 讲风险优先客户交互；Feishu 讲数据合同与受控摄入；Lumen 讲 Provider 抽象和多模态生产。每个案例都从当前可复核证据开始。
4. **边界（15 秒）**：LIVE、生产、准确率、业务 KPI 和部署 source SHA 只在有当前证据时使用；否则明确说 recording、controlled、read-only 或待验证。

## 结束句

“我交付的不是一个看起来会回答的 Demo，而是一条能被业务接住、能被人工复核、能用评估结果继续迭代的 AI 产品链路。”
